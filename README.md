# 📀 Mini Music Player

> A Nostalgic Animated Music Player

This project provides a clean music-player interface where users can play songs, pause them, switch between tracks, view album artwork, track playback progress, and seek through songs.


## How to Use in Your Project?

**You can use this music player as a small overlay in your websites by adding this code to your website.**
